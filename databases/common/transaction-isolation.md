# ШПАРГАЛКА: УРОВНИ ИЗОЛЯЦИИ ТРАНЗАКЦИЙ

## АНОМАЛИИ

| Аномалия                                          | Описание                                                                  | Причина                                                        |
|---------------------------------------------------|---------------------------------------------------------------------------|----------------------------------------------------------------|
| **Грязное чтение** (Read uncommited)              | Чтение незафиксированных данных другой транзакции                         | Отсутствие снимка данных: читаются «сырые» данные из буфера    |
| **Неповторяемое чтение** (Non-repeatable read)    | Повторное чтение той же строки возвращает изменённые данные               | Снимок обновляется на каждый запрос, а не на транзакцию        |
| **Фантомное чтение** (Phantom read)               | Повторный запрос возвращает новые/удалённые строки                        | Снимок фиксирует данные строк, но не диапазон результатов      |
| **Аномалия сериализации** (Serialization anomaly) | Результат группы транзакций невозможен при любом последовательном порядке | Транзакции читают и изменяют пересекающиеся данные параллельно |

## УРОВНИ ИЗОЛЯЦИИ

### Read Committed

- Видит только **зафиксированные данные** на момент начала запроса
- Разные SELECT в одной транзакции **могут видеть разные данные**
- Подходит для **большинства приложений**

### Repeatable Read

- Видит снимок данных на момент **начала транзакции**
- Повторные SELECT **всегда возвращают одинаковые данные**
- Необходима **готовность к повтору** транзакции при сбое

### Serializable

- **Максимальная изоляция** — эмулирует последовательное выполнение
- Использует предикатные блокировки **(SIReadLock)**
- Наибольшие накладные расходы, **чаще всего требует повтора** транзакций
